# شروع به کار و نصب

پکیج `eamirgh/snapp-pay-laravel` یک راهکار جامع و تست‌شده برای اتصال فروشگاه‌های لاراولی به سیستم پرداخت اعتباری و اقساطی **اسنپ‌پی (SnappPay)** است.

این پکیج بر اساس آخرین مستندات فنی ارائه‌شده در [آکادمی اسنپ‌پی (ویرایش ۲.۱)](https://academy.snapppay.ir/self-cms/) طراحی و پیاده‌سازی شده است.

---

## نیازمندی‌های سیستم

- **نسخه PHP**: برابر با `^8.2` یا `^8.3` یا `^8.4`
- **فریم‌ورک لاراول**: نسخه `11.x` یا `12.x` یا `13.x`
- اکستنشن‌های PHP: `ext-curl`، `ext-json`، `ext-mbstring`

---

## مرحله ۱: نصب پکیج

دستور زیر را در ترمینال پروژه لاراولی خود اجرا کنید:

```bash
composer require eamirgh/snapp-pay-laravel
```

---

## مرحله ۲: انتشار فایل تنظیمات

برای ایجاد فایل `config/snapppay.php` دستور زیر را اجرا نمایید:

```bash
php artisan vendor:publish --tag="snapppay-config"
```

---

## مرحله ۳: پیش‌نیاز حیاتی (لیست سفید IP)

::: danger الزام Whitelist بودن IP سرور
برای فراخوانی هر وب‌سرویسی از اسنپ‌پی (از جمله دریافت توکن OAuth)، حتماً باید **IP استاتیک سرور خروجی شما** از قبل توسط تیم فنی اسنپ‌پی در لیست سفید (Whitelist) ثبت شده باشد.
در غیر این صورت، با خطای `Access Denied` یا کد خطای `403 Forbidden` مواجه خواهید شد.
:::

---

## مرحله ۴: تنظیم متغیرهای محیطی (`.env`)

اطلاعات احراز هویت دریافتی از اسنپ‌پی را در فایل `.env` قرار دهید:

```dotenv
# آدرس وب‌سرویس اسنپ‌پی (محیط استیج یا پروداکشن)
SNAPP_PAY_BASE_URL=https://api.snapppay.ir

# اطلاعات پذیرنده
SNAPP_PAY_CLIENT_ID=شناسه_کلاینت
SNAPP_PAY_CLIENT_SECRET=رمز_کلاینت
SNAPP_PAY_USERNAME=نام_کاربری
SNAPP_PAY_PASSWORD=رمز_عبور

# مهلت زمانی ارتباط با درگاه (ثانیه)
SNAPP_PAY_TIMEOUT=30
SNAPP_PAY_CONNECT_TIMEOUT=10
```

> **توجه:** در ابتدای همکاری، اطلاعات محیط **Stage** در اختیارتان قرار می‌گیرد. پس از پیاده‌سازی و برگزاری جلسه دمو (Demo) با کارشناسان اسنپ‌پی، دسترسی محیط **Production** صادر خواهد شد.
